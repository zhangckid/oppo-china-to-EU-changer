# 源码发布流程

[English](RELEASING.md) | 简体中文 | [项目主页](../README.zh-CN.md)

公开源码归档必须根据已审查的 [`release-files.txt`](../release-files.txt) 白名单生成。导出脚本会拒绝缺失文件、仓库外路径和符号链接；只复制清单中的文件，生成 SHA-256 清单及 `.tar.gz`，不会上传或发布。输出目录必须位于仓库之外，以免生成的归档意外进入后续源码导出。

在仓库根目录运行：

```sh
python3 scripts/export_source.py --out ../releases/oppo-china-to-eu-changer
```

将归档附加到发布页前，请检查导出目录与压缩包。白名单只应包含源码和公开文档。ROM、GBL APK、OrangeFox 镜像/ZIP、Platform Tools、设备备份、私有配置、包含序列号的日志和本地测试输出都不得进入归档。不要添加相邻私有工作目录中的完整操作记录。

生成的 `SOURCE-MANIFEST.sha256` 记录了从白名单复制的文件；它不能证明第三方设备镜像的来源或安全性。

发布前请运行 CI 检查，审阅验证记录与支持设备的表述，检查白名单中新加入的文件，并确认归档中无清单外文件或隐私数据。打标签和上传由维护者另行完成。

文档图片也必须逐个列入白名单。实机截图先检查隐私、来源及第三方标识归属；不能将私人相册或整个日志目录加入发布包。`docs/images/guide-*.html` 是离线终端输出排版的源文件，配套 PNG 不应被描述为实机刷机验证。新增文档应同时提供英文与中文版本并维护相互链接。
